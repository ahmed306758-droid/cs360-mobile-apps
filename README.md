# Study Planner Android Application

A native Android study-planning app designed to help students organize assignments, priorities, due dates, and study sessions.

Built for CS 360 (Mobile Architecture and Programming).

---

## Problem

Students often juggle multiple courses, deadlines, and priorities without a single place to track what matters next. This app provides a focused mobile interface for creating and managing assignments, setting priorities, viewing a calendar, and optionally receiving reminders.

---

## What this project demonstrates

- Kotlin and Android application development
- SQLite database design and CRUD operations
- User authentication and session management
- Assignment creation, editing, completion, and prioritization
- Calendar-based planning views
- Responsive mobile UI (XML layouts)
- Permission-aware notification / SMS functionality
