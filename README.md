# Study Planner Android Application

A native Android study-planning application designed to help students organize assignments, priorities, due dates, and study sessions.

## What it demonstrates

- Kotlin and Android application development
- SQLite database design and CRUD operations
- User authentication and session management
- Assignment creation, editing, completion, and prioritization
- Calendar-based planning
- Responsive mobile UI design
- Permission-aware notification/SMS functionality

## Project structure

- `study-planner/` — main Android application
- `sensor-manager/` — supporting Android sensor project
- Supporting planning and documentation files are retained for project context.

## Tech stack

**Kotlin · Android Studio · SQLite · XML · Git/GitHub**
